# 업종별 홈페이지 프로파일 제작 지침

로빈테크는 소상공인 홈페이지 제작을 주력으로 합니다. `/profile/` 갤러리는 업종별 디자인 샘플을 보여 주는 영업 자료이고,
샘플 하나하나의 **디자인 완성도가 이 사업의 첫인상**입니다. 이 문서는 샘플 하나를 만드는 절차와 기준입니다.
spec · 설계 · 구현 · 판정 단계 모두 이 문서를 따릅니다.

기준 예시: `profile/flower-bomgyeol/` (꽃집. Saipua 류 에디토리얼 꽃집을 참고해 새로 만든 샘플)

## 1. 절차

1. **실제 사이트 조사.** 해당 업종의 실제 사이트를 **브라우저로 직접 열어** 10곳 이상 봅니다.
   - 출발점: 웹검색 큐레이션 목록(Colorlib, Really Good Designs, HubSpot 등의 "best <업종> websites"), Mobbin 섹션 검색,
     국내 업종 대표 브랜드 사이트.
   - 도메인이 만료됐거나 다른 사이트(도박 · 광고)로 넘어간 곳, 보안 확인에 막힌 곳은 제외합니다.
   - 국내 소상공인 손님이 쓰는 기능(카카오톡 채널, 네이버 예약 · 지도, 전화)이 들어갈 자리를 함께 봅니다.
2. **후보 4곳 비교.** 가장 세련된 4곳을 고르고, 각각 URL · 한 줄 요약 · 레이아웃 스케치(ASCII) · 어울리는 가게 유형을 적습니다.
   spec 의 가정/열린 질문에 넣고 **사람이 하나를 고릅니다**(orchestrate G1). `auto` 가 아니면 에이전트가 고르지 않습니다.
3. **사진 고르기.** 무료 상업 라이선스 사진(Unsplash 무료, Pexels)에서 후보를 모아 비교판(contact sheet)으로 한 번에 보고 고릅니다.
   Unsplash+ (`plus.unsplash.com`) 는 유료라 쓰지 않습니다.
4. **제작.** 고른 사이트의 *분위기와 수준*만 참고하고, 구성 · 문구 · 로고 · 색 조합은 새로 만들고 **한 단계 더 개선**합니다.
   개선점은 spec 에 적습니다(예: 모바일 첫 화면에서 주문 버튼이 보이게, 한글 타이포 정리, 손님이 찾는 정보 순서).
5. **등록.** `scripts/profiles.py` 에 항목 추가 → `python3 scripts/profile_thumb.py <slug>` → `python3 scripts/build.py`.
6. **확인.** 아래 4절 기준으로 확인하고 커밋합니다.

## 2. 하지 말 것

- 참고 사이트의 레이아웃을 그대로 따라 하기, 문구 · 로고 · 상호 · 사진을 가져오기. "비슷한 분위기, 다른 작품"이어야 합니다.
- 실존 가게 이름이나 실제 주소 · 전화번호 쓰기. 상호는 가상, 주소는 "(가상 주소)", 전화는 `02-000-0000`, 사업자번호는 `000-00-00000`.
- 사이트 공용 `assets/css/style.css`, 헤더, 푸터를 샘플에 쓰기.
- 갤러리 공용 파일(`assets/`, `scripts/build.py` 의 갤러리 부분)을 샘플 하나 때문에 바꾸기. 바꿔야 하면 spec 에 이유를 적습니다.

## 3. 만드는 규칙

- **폴더:** `profile/<slug>/index.html`, `style.css`, `thumb.jpg`, 사진을 담는 `img/`(출처 기록 `img/sources.txt` 포함). 폴더 안에서 완결되는 독립 사이트(상대 경로)라
  나중에 고객 도메인으로 그대로 옮길 수 있어야 합니다. `build.py` 는 이 폴더를 생성하지 않습니다.
- **slug:** `<업종 key>-<가상 상호 로마자>` (예: `flower-bomgyeol`, `food-...`, `clinic-...`).
- **업종 key:** `scripts/profiles.py` 의 `INDUSTRIES` (law, clinic, fitness, beauty, interior, crypto, invest, food, flower).
- **프랜차이즈 업종:** `fitness`(필라테스)와 `beauty`(미용실) 샘플은 한 매장이 아니라 프랜차이즈 본사 브랜드 사이트로 만듭니다.
  지점을 고르는 매장 찾기와 가맹 문의 절을 둡니다.
- **광고 규칙이 있는 업종:** `law`(법무법인) · `invest`(투자자문) · `crypto`(코인 · 가상자산) 샘플의 spec 은 그 업종의 광고 규칙을
  조사해 지켜야 할 내용을 AC 로 적습니다. `clinic` 샘플의 spec 이 의료광고 규칙을 AC 로 적은 것과 같습니다.
- **샘플 표시:** 첫 화면 어딘가에 "로빈테크 디자인 샘플 · 상호와 정보는 가상입니다", 푸터에 "Website by RobinTech".
  사진을 쓰면 푸터에 출처("Photos: Unsplash").
- **`<meta name="robots" content="noindex">`** 를 넣습니다.
- **글꼴:** Google Fonts 와 Pretendard(jsDelivr) 만. 영문 세리프는 숫자가 들쭉날쭉한 서체가 있으니 가격 · 숫자는 숫자 폭이 고른 서체(한글 서체나 모노 서체)로.
- **사진:** 고른 사진을 웹 크기(가로 2000px 이하, JPEG 또는 WebP, 한 장 500KB · 합계 3MB 이하)로 내려받아
  `profile/<slug>/img/` 에 두고 상대 경로(`img/...`)로 씁니다. 외부 사진 주소를 직접 링크하지 않습니다.
  `img/sources.txt` 에 사진마다 `<파일> <사진 페이지 URL> <내려받은 URL>` 한 줄을 적어 라이선스 출처를 남깁니다.
  사진 페이지를 찾지 못하면 페이지 URL 자리에 `-` 를 적습니다. 내려받은 URL 은 항상 적습니다.
- **국내 손님 동선:** 업종에 맞게 카카오톡 채널 상담, 네이버 예약, 네이버 지도, 전화 버튼 자리를 둡니다(링크는 `#` 자리표시).
- **접근성:** 이미지 `alt`, 의미 있는 제목 순서, `prefers-reduced-motion` 에서 애니메이션 끄기.

## 4. 완료 기준

- 1440px 데스크톱과 390px 휴대폰에서 **처음부터 끝까지** 화면으로 확인. 가로 넘침 없음, 글자 겹침 없음.
  헤드리스 Chrome 은 창을 500px 아래로 줄이지 못하므로, 390px 은 `width:390px` iframe 으로 감싸 찍습니다.
- 갤러리(`/profile/`)에서 카드 → 미리보기 → 데스크톱/모바일 전환 → Esc 닫기가 동작.
  `file://` 로 열면 미리보기에 폴더 목록이 보이므로 반드시 `python3 -m http.server 8000` 으로 확인합니다.
- `python3 scripts/build.py` 가 성공하고, 기존 페이지는 바뀌지 않음(`git diff --stat` 으로 확인).
- 참고 사이트와 나란히 놓았을 때 "같은 사이트"로 보이지 않을 것.

MCP와 A2A로 배우는 Multi-Agent 시스템 설계

n8n · LangGraph · CrewAI로 같은 과제를 세 번 구현해 프레임워크 철학을 비교하고, RAG · ADK · MCP · A2A를 거쳐 Claude Code 하네스로 쇼츠 스튜디오 멀티에이전트 팀을 완성한 3일 과정.

개요

‘1인 미디어 회사 자동화’라는 하나의 서사로 3일을 관통합니다. 뉴스 브리핑 → 쇼츠 제작 → 운영 자동화로 이어지며, 2일차에 직접 만든 MCP 서버를 3일차 Claude Code에 연결하는 것이 과정의 클라이맥스입니다.

세션마다 강의 약 20분, 실습 약 35분으로 구성해 손으로 만들어 보는 시간을 최대화했습니다.

커리큘럼

Day 1 · 에이전트 프레임워크

에이전트 기초와 계보 지도 · Claude Code 기초 · n8n supervisor 브리핑 · LangGraph(State, 조건부 엣지, 영속성, HITL) · CrewAI · Flows와 3-way 비교

Day 2 · RAG · ADK · MCP · A2A

RAG 영어 회화 튜터(TTS) · Google ADK 오케스트레이션(LoopAgent/ParallelAgent) · 쇼츠 파이프라인(edge-tts, Pillow, ffmpeg) · 이미지 편집 MCP 서버(HTTP → stdio) · 외부 MCP · A2A 통신

Day 3 · Claude Code 하네스

하네스 해부 · CLAUDE.md · Skills · MCP 연결(공식 서버 + 자작 편집 MCP) · Hooks 가드레일 · Subagents 3인 팀(기획 · 아트디렉터 · 편집자)과 플러그인 패키징

실습 · 사례

  • 같은 과제를 n8n · LangGraph · CrewAI로 세 번 구현하는 3-way 비교
  • Google ADK로 쇼츠 기획 · 제작 파이프라인을 만들어 mp4까지 출력
  • Claude Code 서브에이전트 팀으로 완성하는 shorts-studio

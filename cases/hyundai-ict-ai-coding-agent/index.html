개요

개인 생산성 도구로서의 AI 코딩을 넘어, 조직이 함께 쓰는 개발 체계로 확장하는 것이 목표입니다. 고객 기획서 검토와 미팅을 거쳐 ‘소프트웨어 팩토리’ 방향으로 과정을 설계했습니다.

과정 내내 하나의 FastAPI · React 샘플 저장소를 쓰며, 마지막에는 팀이 저장소에 바로 넣어 쓸 수 있는 하네스 스타터 킷을 남깁니다.

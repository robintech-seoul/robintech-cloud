바이브 코딩 4시간 + 심화 2시간

코딩 경험이 없는 직장인이 무료 ChatGPT만으로 4시간 안에 자기 업무 도구를 만들고, 심화 과정에서 기록이 쌓이는 도구까지 완성하는 실습 과정.

개요

직군이 섞인 비개발자 20명이 조교 없이도 끝까지 따라올 수 있도록, 복잡한 개념 대신 다섯 가지 원칙과 복붙 프롬프트로 설계했습니다.

‘일부러 고장 내고 고치기’, ‘되던 버전 남겨두기’처럼 막혔을 때 스스로 빠져나오는 법을 함께 익혀, 교육이 끝난 뒤에도 혼자 계속 만들 수 있게 하는 데 집중했습니다.

커리큘럼

본편 4시간

워밍업(내 이름 페이지) → 바이브 코딩 5원칙 → 점심 메뉴 룰렛 → 안 될 때 빠져나오기 → 내 분야 도구 만들기 → 발표와 마무리

심화 2시간

만들기 전에 할 일 목록부터 → 기록이 쌓이는 도구와 엑셀 붙여넣기 → 새 대화로 옮겨 타기, 휴대폰 화면 대응 → 옆 사람 3분 테스트 → 앞으로 4주 계획

실습 · 사례

  • 아이디어 카드 12종 — 연차 계산기, 견적 계산기, 복약 체크표 등
  • 일부러 고장 내고 고치기, 버전 3벌 저장과 되돌리기

다룬 기술

ChatGPT단일 HTML브라우저

결과물

  • 복붙 프롬프트 31종(본편 19 · 심화 12)과 수강생 시트 · 치트시트
  • 오프라인에서도 열리는 HTML 교재
